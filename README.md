## 🛠 Using the chat assistant

Once the application opens, you must connect it to your Shopware store. The interface displays fields for your API credentials. Enter your unique Shopware store URL and your administration API key. If you do not have these credentials, log into your Shopware administration panel and navigate to the Integrations menu.

Once connected, you can configure your chatbot settings. You can set up custom greetings, define product recommendation triggers, and customize the visual search interface. All changes save automatically.

## ❓ Frequently asked questions

Do I need coding skills to use this?
No. This application contains a visual menu that allows you to manage settings without writing code.

Does the chat assistant work during non-business hours?
Yes. The AI remains active 24/7 to provide immediate replies to your customers.

Can I modify the responses of the assistant?
Yes. You can edit the database of answers inside the settings menu to ensure the tone matches your business identity.

What happens if the AI does not know an answer?
You can set a fallback option. The assistant will ask the customer to leave an email address for support staff to follow up later.
